# G34 Lab3 SmartBrew AI
Coffee machine simulation for software engineering DVA332 course at MDU

By Kristina Johansson and Omar Farouq Salloum

---

### How to run
1. You must have python installed
2. Clone the repository
3. Go to the directory and run `python main.py`
4. Use the program

---

### List of implemented features
- Create account/login/logout/guest
- Order from the standard menu
- Order saved custom recipes
- Order using natural language
- Get recommndation based on mood, weather, preferences and time of day
- Payment succeeded/failed
- Customize drink
- Save customized recipe to profile
- Manage/view personal preferences
- Access "secure" admin dashboard
- Monitor waste bins and ingredient capacity
- Refill ingredients and empty waste bins
